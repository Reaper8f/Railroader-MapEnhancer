# Map Enhancer Development Roadmap

This roadmap communicates public priorities and planned milestones. It is directional and subject to evolution based on Railroader game updates and community feedback.

---

## Current Status & Milestones

### Completed (v2.0.16)
- [x] Full Railroader 0.6+ native modding port (non-UMM).
- [x] 100% offline slippy map tile subsystem for USGS Topographic and OpenStreetMap packs.
- [x] Pure 5% mathematical hysteresis zoom transitions and LRU texture caching.
- [x] Physics-based Curvature Safe Speed Overlay (INV-026).
- [x] Tactical Locomotive Waypoint Dispatch & Click-to-Couple automation.
- [x] Grade-aware Smart Handbrakes and rolling stock context menu.
- [x] HOPA mechanical defect detection (Hotbox, Low Oil, Handbrakes, Air Leaks, Derailments).
- [x] Turntable clearance fouling detection and bridge stepper controls.
- [x] Sub-segment industry delivery spot track slicing.
- [x] Automated installer (`install.bat`) and tile downloader (`downloadtiles.bat`).

### In Progress
- [ ] Refined route pathfinding ribbons for multi-unit locomotive helper consists.
- [ ] Enhanced Steam Deck on-screen keyboard compatibility for search and filter fields.
- [ ] Additional localized offline tile packs for custom community routes and extensions.

### Planned
- [ ] Interactive industry track order assignment and car routing visualizer directly from the dispatch map.
- [ ] Extended multiplayer dispatch coordination tools (player pings and temporary speed restriction slow-order zones).
- [ ] Integration with upcoming Railroader official features and physics updates.

### Under Consideration
- [ ] Custom sound effects for HOPA defect alerts.
- [ ] Exportable train sheet and dispatch logs (CSV / Web format).
