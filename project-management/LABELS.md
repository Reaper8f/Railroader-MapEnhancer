# Suggested GitHub labels

Create labels as useful; these are recommendations, not required labels.

| Label | Purpose |
|---|---|
| `bug` | Confirmed or suspected defect |
| `feature-request` | New functionality proposal |
| `documentation` | Documentation issue or change |
| `compatibility` | Game version, dependency, or mod compatibility |
| `question` | User question |
| `feedback` | General user feedback |
| `needs-triage` | Not yet reviewed |
| `needs-information` | More details required |
| `confirmed` | Reproduced or otherwise confirmed |
| `duplicate` | Already tracked elsewhere |
| `wontfix` | Not planned for implementation |
| `good-first-issue` | Suitable for a first contribution |
