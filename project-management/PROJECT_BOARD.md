# GitHub Projects setup

Recommended public project board for community-visible work.

## Suggested views

1. **Roadmap** — grouped by status.
2. **Community requests** — issues labelled `feature-request` or `feedback`.
3. **Bugs** — issues labelled `bug`.
4. **Compatibility** — issues labelled `compatibility`.

## Suggested fields

- Status: Triage, Backlog, Planned, In Progress, Done, Won't Do.
- Priority: Low, Normal, High, Critical.
- Type: Bug, Feature, Documentation, Compatibility, Task.
- Target release: optional; only assign when a target is genuinely intended.

## Privacy boundary

Only put work suitable for public disclosure on this board. Keep security investigations, private development tasks, credentials, internal infrastructure details, and unpublished implementation plans in private systems.
