# Map Enhancer v2.0.16

**Release Date:** November 6, 2026  
**Target Game Version:** Railroader 0.6.0+ Experimental (tested on 0.6.2)  
**Package:** `reaper-mapenhancer-2.0.16.zip`  
**Mod Identifier:** `reaper/map-enhancer`

---

## Compatibility

- **Railroader Version:** Railroader 0.6.0+ Experimental (native C# mod).
- **Required Dependencies:** None (standalone native mod; 0Harmony is bundled).
- **Upgrade Notes:** Use the bundled `install.bat` to safely update while preserving existing `settings.json`, `Backgrounds/`, and `Tiles/`.

---

## Highlights

- **Dynamic Slippy Map Backgrounds:** High-performance, 100% local offline slippy tile streaming for both **USGS Topo** (Zooms 12–15) and **OpenStreetMap** (Zooms 12–17) with zero network overhead.
- **Pure 5% Mathematical Hysteresis:** Seamless zoom transitions without flickering or visual blanking.
- **Curvature Safe Speed Overlay (INV-026):** Physics-based curve radius analysis color-coding safe corridor speeds to prevent train derailments.
- **CTC Passing Siding BFS Route Propagation:** Accurate intermediate siding segment classification (Branch Blue vs Mainline Green).
- **Sub-Segment Industry Delivery Slicing:** Accurate sub-segment interval coloring so only active delivery spots are painted.
- **Automated Setup Utilities:** Bundled `install.bat` and `downloadtiles.bat` for seamless updates and tile extraction.
