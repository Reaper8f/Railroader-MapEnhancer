# Release Notes — Railroader Map Enhancer v2.0.18

**Release Date:** November 19, 2026  
**Target Game Version:** Railroader 0.6.0+ / 0.6.3 Experimental  
**Packages:** `reaper-mapenhancer-2.0.18.zip` (Complete), `reaper-mapenhancer-2.0.18-nexus.zip` (Nexus Edition)  
**Mod Identifier:** `reaper/map-enhancer`

---

## 🌟 Major Highlights & New Features

Map Enhancer **v2.0.18** brings official day-one compatibility with **Railroader 0.6.3 Experimental**, resolving all breaking internal API changes, plus an overhaul to the in-game **Update Checker** with smart **Pre-Release detection** and **strict SHA256 assembly verification**.

---

### 1. ⚙️ Full Railroader 0.6.3 Experimental Compatibility

The Railroader 0.6.3 Experimental update introduced significant architectural refactoring to internal Relay, Window, Track, and Ops APIs. Map Enhancer v2.0.18 restores full compatibility across all subsystems:

- **Track Descriptor & Switch Architecture:**
  - Migrated from nested `TrackObjectManager.SwitchDescriptor` to the top-level `Track.SwitchDescriptor` type.
  - Updated all switch state, route, and junction marker lookups to use the official public `TrackDescriptorSet.Switches` dictionary.
- **Window Management & Resizing (RR-1007):**
  - Accommodated Railroader's native window persistence and sizing overhaul.
  - Replaced the deprecated `Window.InitialContentSize` with dynamic `Window.GetContentSize()` and persistent `WindowConfig.DefaultSize` fallback handling, ensuring the map window resizes properly without UI distortion or clipping.
- **Intelligent Dispatch Routing (AutoEngineerPlanner):**
  - Updated `AutoEngineerPlanner.TryPlanRoute` method bindings to include the new `out RouteSearch.Step arrival` parameter along with momentum, start location, and arrival turn handling.
- **Station Agent Window Integration (RR-955):**
  - Adapted reflection lookups to support private field renamings (`_stationId`, `_passengerStop`).
  - Added native fallback to `agent.ResolvePassengerStop(out string stationId)` to ensure clicking station markers opens the station agent depot interface seamlessly.
- **Harmony Patches & Rendering Pipeline:**
  - Fully audited all Harmony patches and IL transpilers against Railroader 0.6.3 binaries (`Unity 6000.3.28f1`), confirming zero regressions in map camera centring, track mesh rendering, or icon placement.

---

### 2. 🔍 Update Checker: Pre-Release Detection & Cryptographic Verification

Refined the in-game update verification engine in **ME Settings (`Ctrl+M`)**:

- **Pre-Release Build Detection:** When running development or test versions ahead of the API's latest public release (`installed > published`), the settings panel now clearly displays `<color=#60A5FA>Pre-release (v{version})</color>` instead of mistakenly reporting "Latest version".
- **Strict SHA256 Matching:** The mod now only reports `<color=#6EE7B7>Latest version (v{version})</color>` when **both** the semantic version and the compiled `MapEnhancer.dll` SHA256 checksum match the official release catalog.
- **No False Update Alerts:** First-map-load update toast notifications are cleanly suppressed when running pre-release or development builds.

---

### 3. 📦 Distribution Packages & Security

- **Complete Package (`reaper-mapenhancer-2.0.18.zip`):** Full mod files, marker graphics, Harmony runtime, automated installer/updater (`install.bat`), and tile downloader (`downloadtiles.bat`).
- **Nexus Mods Edition (`reaper-mapenhancer-2.0.18-nexus.zip`):** 100% clean mod archive with zero batch scripts for instant automated security approval on Nexus Mods.
