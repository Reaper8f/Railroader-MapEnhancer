# Contributing

Thank you for helping improve Map Enhancer.

## Before contributing

1. Search existing issues and discussions.
2. For bugs, use the Bug Report issue form and include reproducible steps.
3. For ideas, use the Feature Request form or start a discussion.
4. Keep reports focused on one issue.
5. Remove personal information, tokens, usernames, and other sensitive data from logs and screenshots.

## What can be contributed here?

This repository is the public project hub. Contributions may include:

- Documentation corrections and improvements.
- Reproducible bug reports and compatibility information.
- Feature proposals and user feedback.
- Community-maintained guides, where approved.

The mod's implementation and internal development repository are maintained separately. Do not submit proprietary source code, credentials, private infrastructure details, or files you do not have permission to share.

## Pull requests

- Explain the problem or documentation gap.
- Describe the change and how it was checked.
- Keep changes small and relevant.
- Do not add compiled mod binaries or large tile archives to Git history. Use GitHub Releases for approved distributable assets.
- Do not add a license or change licensing terms without maintainer approval.

Submitting a contribution does not automatically grant permission to relicense the project or its separately distributed components.
